# Contributing

Thanks for your interest in contributing. This project welcomes issues and PRs.

## Quick Start

1) Fork the repo and create your branch: `git checkout -b feature/my-change`
2) Install dependencies: `npm install`
3) Run the app: `npm run tauri dev`
4) Make your changes and keep commits focused
5) Open a PR with a clear description and screenshots if UI changes

## Guidelines

- Keep changes small and focused.
- Follow existing code style.
- Avoid reformatting unrelated files.
- If you add features, update `README.md`.
- If you fix a bug, explain the root cause in the PR description.

## Testing

There is no automated test suite yet. Please manually verify:

- App launches without errors.
- File open/save works.
- AI rewrite works with your configured endpoint.
